# Hello World Python

Simple HTTP server serving static files from `public/` directory.

## Run

```bash
python app.py
```

Server starts on `http://localhost:8000`.

## Project Structure

```
.
├── app.py          # HTTP server entry point
├── public/         # Static files
│   ├── index.html
│   └── 404.html
└── .gitignore
```
